# 账号估价器

一个不需要安装依赖的离线网页 Demo，用来按以下规则估算游戏账号人民币价值：

- 哈夫币输入单位：可选择“亿”或“m”（million，百万）
- 基础兑换比例：默认 50 万 / 元，可由用户自行修改（最低为 3）
- AW 子弹：默认 0.8 元 / 发
- 红蛋：按发数输入，默认 5 元 / 60 发
- 六套装备：默认 2 元 / 件
- 龟包：默认 1.5 元 / 个
- 有刀皮：用户设定的哈夫币兑换比例降低 1
- 有角色皮肤：兑换比例再降低 1

所有默认价格都可以在页面的“调整市场单价”区域中修改，以适应市场行情变化。

## 本地使用

直接双击 `index.html`，或在项目目录运行：

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。

## 部署到 GitHub Pages

把这几个文件推送到 GitHub 仓库，在仓库的 **Settings → Pages** 中选择从 `main` 分支根目录部署即可。

所有估价逻辑都在 `script.js` 顶部的 `prices` 对象中，后续修改单价不需要改页面结构。
